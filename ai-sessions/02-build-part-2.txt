  ## Step 4 plan: closing and opening a month

  **Rules: `Domain/CycleRules.cs`** (pure, returns `Result`)
  - `NextMonth(latest)`: the month after the latest cycle. If there are no cycles yet, it uses the current business month.
  - `CanOpen(role, anyOpen, nextMonth, dueDate)`:
    - Not a manager: Forbidden.
    - A month is already open: Invalid.
    - Due date outside the month: Invalid.
  - `CanClose(role, cycle)`: managers only, and only an open month.
  - `DefaultDueDate(year, month)`: the 15th (docs/02).
  - `WillCloseAsIncomplete(status)`: every status except Approved and Incomplete.

  **API: `Features/Cycles/`**
  - `POST /api/cycles` → `OpenCycleHandler`:
    - Creates one Not started item per active facility.
    - Owner comes from `Facility.OwnerId`. `PreviousItemId` points to the same facility's item in the latest month. Each item gets a `Created` event with the manager as actor.
    - One `SaveChanges`. A unique (Year, Month) violation from a race returns 409.
  - `GET /api/cycles/{id}/close-preview` → `CloseCycleHandler.PreviewAsync`: rows with facility, status and owner.
  - `POST /api/cycles/{id}/close`:
    - Sets every non-Approved item to Incomplete, with one `StatusChanged` event each, and bumps `Version`.
    - Marks the cycle Closed and sets `ClosedById` and `ClosedAt`. All of this is one transaction.
    - A concurrent transition returns 409.
  - Add `MonthActions` to `OverviewResponse`, so the UI holds no rules:
    - `canClose` for a manager when the selected month is open.
    - `openNext { year, month, defaultDueDate }` for a manager when no month is open.

  **Tests**
  - `CycleRulesTests`: every branch above, plus the December to January rollover.
  - `CyclesTests` handlers on SQLite:
    - Open while a month is open, or open a month that already exists: rejected.
    - Inactive facility: no item.
    - Items get the facility owner, a link to last month's item and a Created event.
    - Due date outside the month: 400. Non-manager: 403.
    - Close with Submitted items: they become Incomplete. Approved items are untouched.
    - After close, a transition returns 400.
    - Preview lists Submitted items too.
    - Open after close: unapproved facilities get Missed last month.

  **Web**
  - `CyclesApi`: `open`, `closePreview`, `close`.
  - `components/close-month-dialog` and `components/open-month-dialog`, laid out as in docs/04.
  - On Overview, show Close month or Open next month only when `monthActions` allows it. After either action, reload into the new or closed month.
